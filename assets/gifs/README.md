# GIFs del perfil

Reemplaza estos archivos **sin cambiar el nombre**. Luego haz commit y push.

| Archivo | Dónde se ve |
|---|---|
| `hero.gif` | Banner del encabezado |
| `building.gif` | Debajo del stack |

Recomendado: GIF o WebP, menos de 2 MB, proporción 16:9.

Si quieres otro nombre o una URL de Giphy, edita las líneas marcadas `gif:hero` y `gif:building` en el `README.md` de la raíz.
